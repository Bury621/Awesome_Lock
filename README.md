# Awesome Lock（宿舍门禁密码锁）v2.0

基于 STM32F407VET6 + ST7735S 1.8" TFT + 电容触摸键盘 + 指纹模块 + 28BYJ-48 步进电机的宿舍门禁锁固件。

本仓库的 `v2.0` 是对早期版本的**重构版**，重点解决实机使用中“经常卡死/自动复位”的问题，并把所有阻塞操作移出中断、改成主循环状态机。

## 快速开始

- 使用 Keil MDK（ARM Compiler 6）打开 `MDK-ARM/Awesome_Lock.uvprojx` 编译；
- 或使用 VSCode + EIDE 打开 `MDK-ARM/Awesome_Lock.code-workspace`；
- 首次烧录后密码为出厂默认 `1234`，管理员密码见 `Config/Config.h` 的 `ADMIN_PWD`。

> 注意：新版把密码存储位置从 `0x0800C000`（Sector 3）改到了 `0x08020000`（Sector 5），
> 因此旧固件里保存的密码不会被沿用，首次启动请使用默认密码，再进管理员菜单修改。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `App/` | 应用初始化、主循环调度、事件队列、调试串口 |
| `Service/` | 门锁业务状态机（`lock_app`）、纯显示层（`ui_views`） |
| `Hardware/` | LCD、键盘、指纹、步进电机、Flash 密码存储 |
| `Config/` | 所有可调参数（密码、角度、超时、锁定次数等） |
| `Core/` | CubeMX 生成的启动/时钟/中断/HAL 配置 |
| `Drivers/` | STM32F4 HAL 与 CMSIS |

## 设计要点

1. **中断只投递事件**：EXTI / UART 接收中断里不读 I2C、不等 UART、不刷屏、不延时。
2. **主循环状态机**：按键、密码、管理员菜单、指纹、开关门、锁定倒计时、休眠全部是非阻塞轮询。
3. **所有超时基于 `HAL_GetTick()`**：`NVIC_PRIORITYGROUP_4` 保证 SysTick 能抢占低优先级中断，HAL 超时可靠。
4. **看门狗只在主循环喂**：任何任务卡死都会在约 10s 后自动复位，而不是“假活”。
5. **显示使用硬件 SPI2**：实机反馈新 LCD 批量刷新方案出现中文异常/重启后已回滚为逐点直写；清屏/矩形/横竖线再改为批量 SPI 传输（整屏约 160 次调用），文字仍逐点绘制保证透明叠加。
6. **密码存储带 CRC 校验**：损坏/空白 Flash 自动回退默认密码，不再把 `0xFF` 当密码。
