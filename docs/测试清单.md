# 硬件联调测试清单

> 重构版只完成了编译/链接验证，**下列项目必须上板逐项确认**。
> 建议先准备：默认密码 `1234`、管理员密码（见 `Config/Config.h`）、可断电的电源、串口调试助手（USART1，9600 8N1）。

## 0. 先接 USART1 看启动日志

把 USB-TTL 接到 USART1（PA9=TX、PA10=RX，9600 8N1），上电应看到：

```
=== BOOT ===
RESET: Power-on
APP: init start
APP: motor ok
APP: keypad ok
APP: lcd ok (fault=0)
LOCK: flash init
LOCK: flash ok
LOCK: ui ok
LOCK: fp init ok
APP: lock ready
```

- 如果反复出现 `=== BOOT ===`，记录 **RESET 行**和 **最后一条 APP/LOCK 行**；
- `RESET: IWDG` = 主循环 10s 没喂狗（卡死/中断风暴）；
- `RESET: BOR` = 供电跌落；
- `[HARDFAULT]` / `[ERROR_HANDLER]` = 程序异常；
- `lcd fault=1` = SPI 发送失败，屏幕可能花屏/黑屏，但系统应继续运行。

把这段日志发出来即可快速定位。

## 0. 烧录前

- [ ] 确认固件大小小于 128KB（当前约 44.7KB），密码存储从 `0x08020000` 开始，不与代码重叠。
- [ ] 确认 `Config/Config.h` 里 `MOTOR_REVERSE` 与电机实际装配方向一致。
- [ ] 记录旧密码（如果旧固件里改过）。新版首次启动会回退默认密码 `1234`。
- [ ] 备份当前工程（git 已包含旧版本，可直接 `git diff` / `git show` 回看）。

## 1. 上电基础

- [ ] 上电后 LCD 正常点亮、无花屏，显示主界面（欢迎来到榕华二 1115 / 已上锁）。
- [ ] 背光默认开启；10 秒无操作后熄屏。
- [ ] 熄屏后按任意键只唤醒，**不会**把该按键当成密码输入。
- [ ] 上电后指纹模块蓝灯呼吸（或至少不报错）。
- [ ] 串口无异常复位日志；连续观察 5 分钟不重启。

## 2. 键盘

- [ ] 依次按 `0~9`、`*`、`#`、`A`、`B`、`C`、`D`，确认每个键都能被识别、无串键。
- [ ] 按一下键只产生一个字符（不会重复输入）。
- [ ] 连续快速按 20 次，无丢键、无卡顿。
- [ ] 拔掉键盘再插上（或短接 SCL 制造一次总线错误），系统应继续运行；后续按键能恢复。
- [ ] 键盘总线被拉低时，主循环仍能刷新界面/倒计时，不会死机。
- [ ] 按键读取失败时不会进入 `Error_Handler`（可观察是否重启）。

## 3. 密码开门

- [ ] 输入 `1234#`，显示“密码正确/欢迎回宿”，电机开门。
- [ ] 约 2 秒后自动关门，约 4 秒后回到主界面。
- [ ] 开门过程中开门指示灯亮，关门后熄灭。
- [ ] 开门后用手轻推门，门应被电机保持住（保持扭矩）。
- [ ] 按 `*` 能退格，按 `D` 能取消并回主界面。
- [ ] 输入超过 31 位后不再接收（显示 7 个星号封顶），不会越界/重启。
- [ ] 空密码按 `#` 无动作。

## 4. 错误密码 / 锁定

- [ ] 连续输错 3 次密码，进入“已锁机”界面，显示剩余秒数并每秒递减。
- [ ] 锁定期间按键/指纹全部无效，但界面仍在刷新、背光正常、系统不重启。
- [ ] 锁定期间观察 10 分钟（或临时把 `FAIL_LOCK_TIME` 改成 10 秒测试），倒计时结束后自动回主界面。
- [ ] 锁定期间断电重启，锁定状态清零（设计如此），可用默认/正确密码开门。
- [ ] 第 3 次输错后密码框应被清空（旧版第 3 次不清空）。

## 5. 管理员

- [ ] 主界面按 `A`，输入管理员密码 `#`，进入管理员菜单。
- [ ] `A/B` 上下移动高亮，`C` 进入，`D` 返回主界面。
- [ ] 修改密码：输入 4 位以上新密码 `#`，显示保存成功并回主界面。
- [ ] 用新密码开门成功；断电重启后新密码仍然有效。
- [ ] 输入少于 4 位按 `#`，提示太短，不写入 Flash。
- [ ] 修改密码后立刻断电（在“保存成功”出现后），重启密码仍为新密码（Flash 回读校验）。
- [ ] 管理员密码错误也会累计失败次数并触发锁定（与开门密码共用计数）。

## 6. 指纹

- [ ] 主界面/密码输入界面按指纹，验证成功开门；失败时模块亮红灯。
- [ ] 指纹验证期间界面不卡顿、按键仍可响应（非阻塞）。
- [ ] 指纹模块拔掉/无应答时，验证请求 3 秒超时后自动恢复，不重启、不卡死。
- [ ] 注册指纹：管理员菜单 → `Register FP`，按提示放手指，完成后显示 FP added 并回主界面。
- [ ] 注册超时（不按手指）20 秒后显示 Timeout 并返回，不卡死。
- [ ] 注册已存在的指纹，显示对应错误码，不崩溃。
- [ ] 清空指纹：`Clear all FP`，完成后显示 FP cleared；再验证任意指纹应失败。
- [ ] 指纹连续失败 3 次后，指纹被禁用，界面提示 Use password；输入正确密码开门后指纹恢复。
- [ ] 验证：主界面刚解锁回主界面后立刻按指纹，不应出现“没按手指也开门”的情况（灯光 ACK 保护窗）。

## 7. 休眠 / 唤醒

- [ ] 主界面 10 秒无操作熄屏。
- [ ] 按键、指纹触摸、人体感应都能唤醒（背光恢复）。
- [ ] 唤醒后的第一次操作不会误输入；**再按一次键应能正常输入**（键盘 IRQ 锁存已在唤醒时读取清除）。
- [ ] 管理员界面/密码输入界面长时间无操作：当前设计只在主界面休眠，确认是否符合预期（如需全界面休眠可扩展）。

## 8. 看门狗 / 故障恢复

- [ ] 在调试器中制造主循环死循环（或长时间断点），约 10 秒后系统应自动复位（IWDG）。
- [ ] 正常运行时不会误复位（连续运行 30 分钟以上）。
- [ ] 修改密码（Flash 擦除）时不触发看门狗复位。
- [ ] 指纹注册 20 秒流程中不触发看门狗复位。

## 9. 压力测试

- [ ] 连续“输密码→开门→自动关门→回主界面” 100 次，无死机、无丢步、无密码错乱。
- [ ] 连续错误密码→锁定→解锁 10 轮，倒计时准确。
- [ ] 连续指纹验证 100 次（成功/失败混合），无协议错位、无重启。
- [ ] 快速反复按 `A`/`D` 切换管理员界面 50 次，无花屏、无卡死。
- [ ] 快速拔插指纹模块/键盘电源 10 次，系统能恢复（可能需要重新上电模块）。

## 10. 显示

- [ ] 主界面、密码界面、成功界面、锁定界面、管理员菜单、注册提示、提示信息界面均完整显示，无越界、无重叠。
- [ ] 密码星号最多 7 个，退格正常。
- [ ] 锁定倒计时数字右对齐/不溢出。
- [ ] 宿舍楼和床铺图标位置正常（床铺图标已修正 8 字节头偏移，旧版会错位/越界读）。
- [ ] 全屏刷新无花屏、无错位（已恢复旧版逐点直写）。

## 11. 回归检查（与旧版对比）

- [ ] 开门角度与旧版一致（75°，约 0.84 秒）。
- [ ] 开门速度与旧版一致（980µs/步）。
- [ ] 密码长度、管理员密码、默认密码行为一致。
- [ ] 风扇/其他外设（如果有）未受影响。

## 12. 失败时怎么排查

| 现象 | 优先检查 |
| --- | --- |
| 上电黑屏 | 背光 PB14、SPI2 引脚、`LCD_Init()` 是否被调用、3.3V |
| 屏幕花屏/颜色不对 | `LCD_FlushArea()` 的 R/B 交换、MADCTL、窗口偏移 |
| 按键无反应 | PB5 EXTI、I2C1 地址 `0x65`、`Keyboard_ReadRaw()` 返回值 |
| 指纹无反应 | UART5 波特率 57600、PC12/PD2、`UART5_IRQHandler` 是否链接、模块 5V 供电 |
| 指纹一直超时 | 协议长度/校验和、模块返回帧的实际格式（用逻辑分析仪抓 UART） |
| 门不动/方向反 | `MOTOR_REVERSE`、PE11~PE14 接线、28BYJ-48 公共端 5V |
| 门开到一半停 | `OPEN_DOOR_STEP_US` 太小导致丢步，增大到 1200~1500 试 |
| 频繁重启 | 看门狗 10s 是否被 Flash 擦除/长阻塞超过；串口打印启动信息定位 |
| 改完密码重启又变默认 | Flash 地址/扇区、CRC 记录、`FLASH_EEPROM_SetPassword()` 返回值 |
